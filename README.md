# れんさ道場

落ちものパズルの「連鎖」を、お手本どおりに置きながら覚える練習ゲーム(PWA)。

- レッスン: 4つで消える → 2連鎖 → 3連鎖 → 4連鎖。置く場所がうすく光り、そのとおりに置けるつぶが届く。違う場所なら置き直し。「おてほん」で自動再生。色の組み合わせは毎回変わる
- かるくプレイ: 自由モード。連鎖数・最大連鎖・点数
- 縦持ちスマホ向けボタン操作。PCは矢印・Z/X・スペース

レッスンの手順は tools ではなく app.js の LESSONS。連鎖数はシミュレーションで確認済み(1/2/3/4連鎖)。

## 開発
- `node serve.js` → http://localhost:5401
- `node tools/make-icons.js` / `node tools/build-pages.js` → docs/
